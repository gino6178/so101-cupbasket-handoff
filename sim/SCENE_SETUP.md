# 實機場景佈置表（頂部斜拍 C920 + 兩支腕部 OV9732）

本表對應模擬中的「真實設定」（`WX_REAL=1`、`WX_TOP_POSE=A`），以及幾何設定檔 `cb3_geo.env`。實機請照這張表佈置；表中的容許誤差與擾動範圍都是模擬訓練時用的值。

## 1. 座標系

- 原點：兩支手臂底座連線的中心線上，x = 0 處（見下表），z 量到桌面。以下高度一律「從桌面算起」。
- x 軸：從左臂底座指向右臂底座。兩臂面對面，底座都在 y = 0 上。
- y 軸：垂直於 x、平行桌面（右手座標，z 朝上）。

| 項目 | 位置 |
|---|---|
| 左臂底座 | x = −0.07 m，y = 0 |
| 右臂底座（面對左臂） | x = +0.41 m，y = 0 |
| 籃子列中心 | x = +0.17 m，y = 0；三個籃子沿 y 方向排成一列 |
| 杯／碗初始區 | x ∈ [−0.08, 0.42] m，\|y\| ∈ [0.12, 0.34] m（籃子列兩側） |

## 2. 頂部相機：Logitech C920，斜拍（姿態 A，11/8 定案）

| 項目 | 數值 |
|---|---|
| 鏡頭位置 | x = −0.30 m（左臂底座正後方 23 cm），y = 0（中心線上），**桌面上方 0.818 m** |
| 瞄準點 | 桌面上 (x, y) = (0.152, 0)，也就是左臂底座前方 22 cm |
| 俯角 | 向下 61.1°；光軸到瞄準點距離約 0.94 m |
| Roll | 0°：影像水平邊平行於桌面 y 軸，影像長邊沿 y |
| 解析度／幀率 | 1280×720 @ 30 fps（MJPEG），感知處理時縮成 640×360，10 Hz |
| 視角 | 水平 70.4° × 垂直 43.3° |
| 對焦／曝光／白平衡 | 全部鎖定手動：對焦約 0.9 m，固定曝光，白平衡固定約 4500 K |
| 工作區在畫面中的範圍 | 640×360 畫面上 u 約 92–548、v 約 50–315，四周都有留邊 |

**擺放容許誤差：** ±3 cm、±3°，焦距 ±3%。模擬中每個回合都在這個範圍內隨機。

**擺好後一定要做標定，這是必要條件。** 模擬中感知使用的是「標定後」的相機姿態，殘差為 ±5 mm、±0.5°、焦距 ±0.5%。建議做法：
1. 先用棋盤格標定 C920 的內參與畸變。
2. 在桌面已知位置貼 4 個以上 AprilTag，例如工作區四角 (−0.12, ±0.38) 與 (0.46, ±0.38)，用 solvePnP 求外參。
3. 驗收：重投影誤差小於 1 px；用一個放在已知位置的杯子檢查，定位誤差應小於 1 cm。
4. 相機或桌子被碰到時要重新標定。

**不標定的後果**（舊斜拍設定，學生 g3w，512 回合，只動相機、感知仍用名義姿態）：

| 相機偏差 | 名義 | x +2 cm | x −2 cm | y +2 cm | z +3 cm | yaw +2° | pitch +2° | pitch −2° |
|---|---|---|---|---|---|---|---|---|
| 聯合成功率 | 56.1% | 32.0% | 21.7% | 48.4% | 38.7% | 52.5% | 1.8% | 4.1% |

俯仰角只要偏 2° 就幾乎全部失敗，所以標定是必要的。

### 為什麼選姿態 A，而不是從籃子列側邊拍（姿態 B／B2）

- 姿態 B 原規格：eye (0.17, −0.60, 0.80)，看向 (0.17, 0, 0)，桌面以上要減 3.2 cm。近側物件投影到畫面 v ≈ 353/360，再加 ±3° 就會被裁掉。
- 姿態 B2：B 後移 5 cm、抬高 5 cm，瞄準點往近側移 3 cm，四周留邊大約 35 px。

三種姿態用同一套流程比較：各收 2 萬張分割資料，各自訓練分割器（mIoU 0.924 / 0.921 / 0.919），teacher 在真實估計上跑約 1000 回合。

| 誤差（cm，平均 / p90） | A | B | B2 |
|---|---|---|---|
| 杯（看得到、無遮擋） | **1.37 / 2.31** | 1.93 / 3.33 | 2.00 / 3.35 |
| 碗（看得到、無遮擋） | **1.11 / 1.71** | 1.38 / 2.27 | 1.45 / 2.36 |
| 疊放中的杯 | **2.29 / 2.96** | 2.86 / 4.21 | 2.95 / 4.44 |
| 籃子中心 | **0.98 / 1.67** | 1.25 / 2.32 | 1.29 / 2.39 |
| 籃子 yaw（°） | **1.7 / 3.4** | 2.0 / 4.2 | 2.0 / 4.2 |
| 手臂旁的杯被擋住的時間比例 | 33% | 27% | 27% |
| 手臂旁的碗被擋住的時間比例 | 44% | 44% | 47% |
| 無遮擋時碗的凍結比例 | **14%** | 20% | 20% |

姿態 A 除了「手臂旁的杯」遮擋略多以外，每一項都比較好，所以選 A。B 與 B2 從籃子列的一端沿 y 方向看過去，遠端物件距離比較遠，三個籃子在深度方向上也會互相重疊。

### 已知限制

- **疊放高度：** 用「同型、3 cm 內、較不可見者在下」推估層數，正確率杯約 81%、碗約 75%。
- **倒下偵測：** 斜拍下遮罩長寬比分不出杯子是直立還是倒下，所以真實設定一律回報直立。模擬中倒下的情況約佔 4% 的時間。
- **定位用的高度平面：** 依物件類型使用已知高度，射線與「放置面 + 質心高度」的平面求交。杯用 3.5 cm、碗用 3.0 cm，這兩個值是從模擬統計校準出來的。放置面是桌面；落在估計的籃子範圍內時改用籃底高度；疊放時每多一層加一個疊放間距（杯約 20 mm、碗約 5.6 mm）。

## 3. 腕部相機：OV9732（兩支）

| 項目 | 數值 |

## 4. 物件與顏色

| 物件 | 顏色（hex） | 尺寸 |

| 藍杯／藍碗 | #1F4CF2 | |

| 籃子 B（木色） | #A88052 | 同上 |
| 籃子 C（深灰） | #525761 | 同上 |
| 桌面（模擬預設） | #8C7359 | 模擬中也會隨機成白、淺木、深木、灰、黑、深色墊 |
| 手臂 | #FF3804（橘色） | |

- 桌面與墊子**不要用紅、綠、藍色**，也不要用和籃子相近的灰色或木色花紋。
- 籃子長邊要沿 x 方向（兩臂連線方向），偏差在 ±20° 以內；三個籃子排成一列，中心在 x = 0.17 m。
- **桌上杯碗之間，口緣到口緣至少留 3 cm**（11/9 起，模擬 `BITIDY_CB_OBJ_SEP=0.03`）。間距只有 1.5 cm 時，手臂夾取時常碰到旁邊的容器。

## 5. 光線

- 用漫射光，避免強烈的直射陰影；模擬中最多加 3 塊柔和陰影來訓練。
- 不要用彩色燈。色溫在 3000–6500 K 都可以，模擬中有隨機，但相機白平衡要鎖定。
- 曝光固定；模擬中曝光在 0.6–1.4 倍之間隨機。

## 6. 時序與其他

- 頂部感知 10 Hz，延遲 66–133 ms；腕部影像延遲 33–100 ms；動作延遲 0–2 個控制步。
- 馬達編碼器解析度為 4096 tick/轉，模擬中加了偏差與雜訊。
- 每次開機都要確認：相機沒被移動過（必要時重新標定）、桌面上沒有多餘的紅綠藍物品。
